# GHotel

GHotel is a modern hotel management and booking platform designed to streamline room reservations, guest management, and hotel operations. The project combines a Java-based backend with a TypeScript-driven frontend for a scalable and maintainable web application.

## Overview

GHotel aims to provide a complete solution for:
- Managing rooms and availability
- Handling guest reservations
- Tracking bookings and customer information
- Supporting hotel administration workflows
- Delivering a clean and responsive user experience

This repository contains the core application source, UI assets, and supporting configuration needed to run the project locally.

## Features

- Hotel room listing and availability management
- Reservation and booking workflow
- Guest and customer profile management
- Admin dashboard for operational monitoring
- Responsive frontend interface
- Secure backend APIs
- Clean separation between application logic and presentation layer

### Tech Stack

* **Backend:** Java (Spring Boot)
* **Frontend:** TypeScript, Angular
* **Database:** PostgreSQL
* **ORM / Persistence:** Hibernate / JPA
* **Security & Auth:** JWT 
* **Build:** Maven
